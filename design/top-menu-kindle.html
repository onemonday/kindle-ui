Где открыто меню

Как переводятся пункты

  • Подменю → строка со стрелкой, открывает страницу с «←».
  • Флажок → переключатель справа.
  • Выбор одного → кружки; выбранное видно справа в родительской строке.
  • «Sort by: name» → название слева, значение справа.
  • Первая буква названий и значений заглавная: «name» → «Name».
  • Подпись только у неочевидных пунктов: Start with, Style tweaks, OPDS catalog.
  • Разделитель → отступ с тёмной линией.
  • Недоступный пункт → серый текст.
  • Длинный список прокручивается пальцем или колесом, после отпускания строка встаёт ровно по верхнему краю. ▲▼ прокручивают на экран.
  • Шеврон над заголовком открывает верхнюю шторку, ⋮ — классическое меню.
