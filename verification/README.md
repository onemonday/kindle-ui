# Проверка на Kindle Paperwhite 6

Снимки получены чтением /dev/fb0 по SSH с реального устройства, 1272×1696, 8-bit grayscale, stride 1272. Это не макеты.

Проверено 2026-09-15: штатный Power → Restart (новый PID reader.lua), открытие книги без смены страницы 276/608, панели, Aa → настройки → Back, прогресс-бар → Skim document, Home → домашний экран SimpleUI.

Обнаружено и исправлено: обработчик SimpleUI после загрузки KOReader имеет тип callable table, поэтому проверка type == function пропускала его.

Снимок кадрового буфера подтверждает отрисовку интерфейса, но не показывает физические остаточные следы E Ink.
