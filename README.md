# Kindle Drawer для KOReader

Плагин открывает верхнюю шторку свайпом вниз. В книге нажатие на верхнюю область открывает отдельную Quick actions panel, а обычный жест нижнего меню открывает настройки чтения. Все три панели можно отключать независимо. Кнопка «Все настройки» открывает штатное верхнее меню KOReader.

## Обновление

Закройте KOReader и замените папку `kindle-drawer.koplugin` содержимым нового архива. Перезапустите KOReader. Сохранённые настройки видимости сохранятся, кнопка Power появится по умолчанию.

## Исправления выбора значений и отступов

Выбор значения открывается внутри нижней шторки. Кнопка **Back / Назад** возвращает исходную вкладку и страницу списка без применения изменений. Касание значения применяет его и возвращает к параметрам. Длинный список листается стрелками или горизонтальным свайпом.

Выбор, точный ввод, справка и подтверждение сохранения по умолчанию открываются внутри нижней шторки. Кнопка «Назад» возвращает к предыдущему экрану и странице.

Строки с ползунками стали выше: 126 вместо 102 единиц макета, с отступом 18 единиц над числом. Строки переключателей и выбора уменьшены до 68 единиц. Раскладка страниц и области нажатий используют одни и те же размеры строк.

## Quick actions panel

Панель быстрых действий открывает две панели по краям страницы. Сверху находятся часы, батарея, Home (экран SimpleUI, если плагин установлен; иначе домашняя папка KOReader), иконки Aa (Layout settings), оглавления, закладок, Page browser и закрытия, ниже — название книги. Нажатие на центральный шеврон открывает верхнюю шторку управления устройством. Снизу находятся номер страницы, процент и прогресс-бар; нажатие на нижнюю полосу открывает Skim document. Главный экран не прокручивается. Касание текста книги или иконки закрытия скрывает обе панели.

Aa открывает настройки оформления. «Назад» справа от вкладок возвращает Quick actions panel. Если нижняя шторка отключена, Aa открывает штатные настройки KOReader.

## Нижняя шторка

Обычный жест нижнего меню сразу открывает настройки оформления, без быстрых действий. Текстовые вкладки сверху, подчёркивание активной вкладки, тонкие разделители, ползунки и переключатели используют оформление панели Kindle. Набор параметров остаётся от KOReader, без Kindle Themes и других настроек Amazon.

- **Font / Шрифт**: размер, насыщенность и контраст, точная настройка размера, интервалы и остальные параметры текста.
- **Layout / Макет**: поворот, колонки и поля.
- **Page / Страница**: режим просмотра и рендеринга; для PDF также масштабирование и параметры подгонки страницы.
- **More / Ещё**: остальные параметры текущего документа, включая встроенные стили, шрифты и обработку изображений.

Плагин читает текущие определения `ReaderConfig.options`. Для EPUB и PDF наборы различаются; каждый исходный параметр попадает в одну вкладку. Условия показа и доступности, события применения, точные значения остаются штатными. Отсутствие сенсорного экрана сохраняет штатную нижнюю панель.

Стрелки справа внизу и горизонтальные свайпы листают страницы длинной вкладки. Свайп вниз и Back возвращают предыдущий экран, а с главного экрана закрывают панели. Касание над панелью настроек закрывает её. Кнопка **KOReader settings / Параметры KOReader** открывает исходную нижнюю панель. Одновременно открыта только одна шторка.

Ползунки выбирают штатные предустановленные значения. Если KOReader предлагает точную подстройку, кнопки «−/+» сохраняют её шаг. Стрелка у параметра открывает встроенный редактор точного значения. Для парных настроек доступны два независимых ползунка. Нажатие на число открывает цифровую клавиатуру, а для контраста — список значений его шкалы. «Готово» возвращает число в редактор; «Применить» меняет настройку книги. «Назад» отменяет неприменённые изменения. Строка значения по умолчанию восстанавливает его в редакторе; «Сделать по умолчанию» открывает подтверждение и сохраняет настройку для новых книг. Значение применяется после отпускания ползунка, чтобы не пересчитывать книгу на каждом движении пальца. Если вручную введённое число находится вне диапазона предустановок, кнопка в сторону за пределы диапазона оставляет его прежним.

Удержание заголовка открывает справку внутри шторки с перелистыванием длинного текста. Удержание иконки или точки ползунка предлагает сохранить выбранную предустановку по умолчанию. Для переключателей удерживайте переключатель, затем нужное значение в появившемся списке. Недоступные параметры не применяются; рядом с ними стоит «—».

## Настройки панелей

В **More tools → Kindle Drawer** шесть пунктов:

1. **Enable top drawer** — включить верхнюю шторку.
2. **Top drawer settings** — открытие верхней шторки, видимость кнопок, заголовок и затемнение фона.
3. **Enable bottom drawer** — включить нижнюю шторку.
4. **Bottom drawer settings** — открытие нижней шторки и запоминание последней вкладки.
5. **Quick actions panel** — включить панель быстрых действий по нажатию сверху.
6. **Full refresh on open and close** — полное обновление экрана для всех трёх панелей.

В русском интерфейсе эти пункты переведены. Сохранённые настройки верхней шторки продолжают работать. Нижняя шторка включена по умолчанию, фон над ней остаётся страницей книги. Общий параметр полного обновления применяется при следующем открытии панели.

## Язык, заголовок, питание и SSH

Плагин использует русский для интерфейса KOReader на русском, английский для всех остальных языков. После смены языка перезапустите KOReader, как предлагает сама программа.

В подменю **Top drawer settings / Настройки верхней шторки**:

- **Заголовок шторки / Header title** редактирует надпись слева сверху. Пустая строка скрывает её. Длинный заголовок сокращается по ширине, не перекрывая заряд батареи.
- **Кнопки шторки / Drawer buttons** включает и скрывает кнопки, в том числе Power и SSH server.
- **Power / Питание** открывает **Restart / Перезапуск**, **Sleep / Сон**, **Exit KOReader / Выйти из KOReader**. Restart перезапускает KOReader, Sleep усыпляет устройство, Exit закрывает KOReader. Недоступные устройству действия отключены.
- **SSH server / SSH-сервер** по умолчанию скрыта. Включите штатный SSH-плагин KOReader и затем эту кнопку. Она переключает сервер через штатный обработчик SSH-плагина: первое нажатие запускает сервер, следующее останавливает. Порт, авторизация и поведение активных соединений при остановке определяются настройками штатного SSH-плагина. Для подключения по Wi-Fi включите Wi-Fi.

## Установка

1. Распакуйте `dist/kindle-drawer.zip`.
2. Скопируйте папку `kindle-drawer.koplugin` целиком в `koreader/plugins/` на Kindle. При стандартной установке по USB это `/mnt/us/koreader/plugins/kindle-drawer.koplugin/` на устройстве.
3. Полностью перезапустите KOReader.
4. Коснитесь верхней зоны страницы или проведите сверху вниз. Учитываются настройки KOReader, разрешающие касание или свайп для открытия меню.

Настройки плагина находятся в штатном меню: **Все настройки → Инструменты → Другие инструменты → Шторка Kindle**. Названия разделов зависят от локализации KOReader. Здесь можно открыть шторку, отключить замену меню и включить или скрыть каждую дополнительную кнопку. Действие «Шторка Kindle» также регистрируется в списке действий для жестов.

Для удаления закройте KOReader, удалите папку плагина и запустите KOReader снова. Плагин не меняет исходники программы.

## Что работает

- Круглые контурные иконки, часы, дата, заряд батареи и нижняя ручка закрытия.
- Wi-Fi, тёмный режим, отправка текущего прогресса через KOSync, включение подсветки.
- Слайдеры яркости и теплоты с кнопками «−» и «+». Есть касание и перетаскивание.
- Закрытие свайпом вверх, нажатием на ручку или область под шторкой.
- Выбор видимых кнопок. «Все настройки» нельзя скрыть.
- Масштабирование под размер и ориентацию экрана.

Кнопки Wi-Fi и подсветки появляются только при поддержке устройством. Синхронизация видна в открытой книге при включённом KOSync; сначала настройте учётную запись в KOSync. Эта кнопка **отправляет прогресс**, а не запускает Amazon Sync и не скачивает прогресс другого устройства.

Bluetooth, автояркость и расписание теплоты с исходного скриншота в эту версию не входят. Wi-Fi управляет только Wi-Fi, поэтому кнопка не названа авиарежимом. Теплота отображается в шкале 0–24 и пересчитывается в публичную шкалу KOReader 0–100; яркость использует диапазон драйвера устройства. Числа над обоими ползунками следуют за ручкой. Дополнительные кнопки выбираются из встроенного набора, произвольные команды и перестановка пока не поддерживаются.

## Удержание кнопок

Удержание кнопки верхней шторки открывает её настройки:

- **Wi-Fi** открывает список сетей. Если Wi-Fi выключен, KOReader сначала включает его и после подключения показывает список.
- **Frontlight / Подсветка** открывает штатное окно подсветки KOReader.
- **Sync / Синхронизация** и **SSH server / SSH-сервер** открывают главное меню KOReader сразу в подменю Progress sync и SSH server. «Назад» ведёт по обычному дереву меню.
- **Power / Питание** и **All Settings / Все настройки** работают как при нажатии. Dark Mode удержание игнорирует: других настроек у тёмного режима нет.

## Затемнение и обновление e-ink

Затемнение настраивается в **Top drawer settings**, полное обновление находится в основном меню **Kindle Drawer**:

- **Затемнять фон / Dim background** — включён по умолчанию. Под шторкой рисуется шахматная сетка с чёрными клетками 3×3 физических пикселя и прозрачными промежутками такого же размера. Страница остаётся видна. Сетка сохраняет чёрный цвет в обеих темах и исчезает при закрытии.
- **Полное обновление при открытии и закрытии / Full refresh on open and close** — выключен по умолчанию. При включении KOReader выполняет полное обновление всего экрана при открытии и закрытии шторки, чтобы убирать остаточные следы. При движении слайдеров остаётся обычное обновление.

Изменения применяются при следующем открытии шторки. Полное обновление может сопровождаться обычной для e-ink вспышкой.

## Состояния кнопок и батарея

У Wi-Fi, Dark Mode, Frontlight и SSH server включённое состояние показано залитым кругом с контрастным символом, выключенное — контуром. В светлой теме активный круг чёрный, в тёмной — белый. Подписи On / Off убраны. Кнопки действий остаются контурными.

Рядом с процентом заряда отображается батарея: заполнение пропорционально заряду. Во время зарядки вместо заполнения появляется молния, процент остаётся видимым. Подключение и отключение питания обновляет значок при открытой шторке. При неизвестном значении показывается «—» и пустой контур.

## Исправления отображения

Размер шрифта больше не масштабируется дважды через DPI KOReader. Координаты, шрифты и иконки используют одну шкалу относительно референса шириной 750 пикселей. Для двух рядов кнопок и двух слайдеров высота шторки составляет 752 единицы референса. Дополнительный ряд увеличивает высоту; на небольшом экране шторка уменьшается, чтобы помещаться.

SVG отрисовываются с `alpha = true` и `original_in_nightmode = false`. Прозрачность сохраняется, дополнительная инверсия прямоугольника изображения в ночном режиме отключена. Иконки, ползунки и стрелка инвертируются вместе с остальным интерфейсом. Проверка параметров покрывает все SVG-вызовы.

## Проверка

API сверены с [исходниками KOReader](https://github.com/koreader/koreader/tree/945470bf7f5f1db822c6e83b4914b03a6ab9fbeb). Astra Low проверила новую нижнюю шторку. Исправлены замечания о быстрых свайпах, сохранении значений по умолчанию, управлении без touch и нестандартных значениях ползунков. Повторная проверка исправлений прошла без новых замечаний.

Автоматические тесты запускают код плагина в Lua 5.1 с заменами интерфейса и устройства:

```sh
python3 -m venv /tmp/kindle-drawer-tests
/tmp/kindle-drawer-tests/bin/pip install lupa
/tmp/kindle-drawer-tests/bin/python tests/run.py
```

Они проверяют перехват и восстановление меню, выход через «Все настройки», скрытие кнопок, фильтрацию возможностей, пределы слайдеров, безопасное перетаскивание, закрытие и геометрию в двух ориентациях. `dist/preview-en.png`, `dist/preview-ru.png` и соответствующие файлы `*-dark.png` строятся по вызовам отрисовки плагина с метриками Arial и SVG-рендерером resvg. В тёмных превью моделируется общая инверсия экрана. Светлая и тёмная версии проверены визуально; они не заменяют скриншот настоящего KOReader. Генератор: `tests/render.py`, дополнительные зависимости `pillow`, `resvg-py` и системный Arial на macOS. Тесты также проверяют отсутствие двойного DPI-масштаба, выбор языка, события питания, сохранение/отмену заголовка и переключение SSH. `tests/nightmode.py /path/to/koreader` отдельно запускает настоящий метод `ImageWidget:paintTo` из указанных исходников с записывающей заменой framebuffer: воспроизводит прежнюю инверсию прямоугольника и проверяет исправленный вариант в двух темах с обоими форматами альфа-канала.

Предыдущая версия проверена пользователем на Kindle; её фотографии выявили ошибки порядка окон и отступов, исправленные в этой версии. Автоматические проверки новой версии не заменяют проверку интерфейса на устройстве. Конкретная версия установленного KOReader неизвестна. После установки проверьте открытие/закрытие, «Все настройки», Wi-Fi и оба слайдера. Если плагин не загрузился, сохраните `koreader/crash.log` и версию KOReader для диагностики. Перехват жестов может конфликтовать с другими плагинами, меняющими верхнее меню.

### Проверка нижней шторки

```sh
/tmp/kindle-drawer-tests/bin/python tests/bottom.py /path/to/koreader
/tmp/kindle-drawer-tests/bin/python tests/render_bottom.py /path/to/koreader
```

`bottom.py` загружает настоящие `ConfigDialog`, `creoptions`, `koptoptions` и `defaults.lua` из указанной копии KOReader. Проверяет полноту переноса параметров, штатное применение и точный ввод, перехват `ui.config`, закрытие, общий refresh и регрессии из ревью. Тест порядка окон использует настоящий `UIManager:show`. Дополнительные проверки проходят по доступным точным редакторам CRE/KOPT: парные значения, границы, отмена черновика, сохранение по умолчанию, индексы контраста, вложенный возврат и закрытие до отложенного применения. Интерфейс, устройство и обработка событий документа заменены тестовыми объектами; реальный движок книги не запускается.

Превью `dist/bottom-{font,layout,page,more}.png` и варианты `*-dark.png` строятся по вызовам отрисовки. Они проверены визуально, но не заменяют запуск на Kindle. Для обновления скопируйте папку плагина из нового `dist/kindle-drawer.zip` и перезапустите KOReader.

### Установка и проверка через SSH

Инструкция для агентов: [работа с Kindle через SSH](docs/kindle-ssh.md). Описаны установка версии, штатный перезапуск, удалённые нажатия, получение настоящих снимков экрана и обязательная очистка тестовых файлов на устройстве.
